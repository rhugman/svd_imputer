🎓 ALGORITHM OVERVIEW
════════════════════════════════════════════════════════════════════════════════

1. VALIDATION
   ├─ Check datetime index
   ├─ Verify sorting
   ├─ Remove all-NaN rows
   └─ Validate sufficient data

2. RANK ESTIMATION (if not provided)
   ├─ Fill NaN with column means
   ├─ Compute SVD: X = U Σ V^T
   ├─ Calculate cumulative variance
   └─ Select rank for threshold (e.g., 95%)

3. ITERATIVE SVD IMPUTATION
   ├─ Initialize: Fill NaN with column means
   ├─ Loop until convergence:
   │  ├─ Compute SVD
   │  ├─ Low-rank approximation (rank r)
   │  ├─ Update missing values only
   │  └─ Check convergence (Frobenius norm)
   └─ Return imputed matrix

4. RETURN
   └─ DataFrame with imputed values
