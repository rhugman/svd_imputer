✅ THREE UNCERTAINTY METHODS IMPLEMENTED:

1. Monte Carlo ('monte_carlo')
   - Fast constant uncertainty band based on validation
   - Masks observed values, imputes, and compares
   - Returns: RMSE, MAE with 95% confidence intervals
   - Use case: Quick analysis, reporting
   - Speed: ⚡⚡⚡ (10-30 seconds for n=100)

2. Bootstrap ('bootstrap')
   - Point-wise uncertainty via resampling
   - Resamples observed data, imputes multiple times
   - Returns: DataFrame with lower/upper bounds for each value
   - Use case: Detailed point-wise uncertainty
   - Speed: 🐌 (1-2 minutes for n=50)

3. Hybrid ('hybrid')
   - Combines Monte Carlo validation + Bootstrap
   - Scales Bootstrap intervals by MC RMSE
   - Returns: Calibrated point-wise confidence intervals
   - Use case: Maximum accuracy for publications
   - Speed: 🐌 (2-3 minutes)


🔧 NEW API METHODS
════════════════════════════════════════════════════════════════════════════════

1. estimate_uncertainty(df, n_repeats=100, mask_strategy='block', ...)
   - Standalone uncertainty estimation
   - Returns dict with RMSE/MAE statistics
   
2. fit_transform(df, return_uncertainty=True, uncertainty_method='...', ...)
   - Enhanced method with optional uncertainty
   - Backward compatible (default: no uncertainty)
   - Returns (df_imputed, uncertainty_dict)
   
3. get_confidence_intervals(df_imputed, uncertainty_dict, confidence=0.95)
   - Extracts lower/upper bounds from uncertainty dict
   - Works with all three methods
   - Returns (df_lower, df_upper)


📊 USAGE EXAMPLES
════════════════════════════════════════════════════════════════════════════════

Example 1: Monte Carlo (Recommended)
────────────────────────────────────────────────────────────────────────────────
from svd_imputer import Imputer

imputer = Imputer()
df_imputed, unc = imputer.fit_transform(
    df,
    return_uncertainty=True,
    uncertainty_method='monte_carlo',
    n_repeats=100
)

df_lower, df_upper = imputer.get_confidence_intervals(df_imputed, unc)
print(f"RMSE: {unc['rmse']:.3f} ± {unc['rmse_std']:.3f}")


Example 2: Bootstrap (Point-wise)
────────────────────────────────────────────────────────────────────────────────
df_imputed, unc = imputer.fit_transform(
    df,
    return_uncertainty=True,
    uncertainty_method='bootstrap',
    n_bootstrap=50
)

df_lower, df_upper = imputer.get_confidence_intervals(df_imputed, unc)


Example 3: Hybrid (Best Accuracy)
────────────────────────────────────────────────────────────────────────────────
df_imputed, unc = imputer.fit_transform(
    df,
    return_uncertainty=True,
    uncertainty_method='hybrid',
    n_repeats=50,
    n_bootstrap=30
)

df_lower, df_upper = imputer.get_confidence_intervals(df_imputed, unc)


Example 4: Visualization with Uncertainty Bands

💡 RECOMMENDATIONS
════════════════════════════════════════════════════════════════════════════════

For different use cases:

Quick Analysis:
  → Monte Carlo (n_repeats=100)
  → Fast, good enough for most cases

Publication/Reporting:
  → Hybrid (n_repeats=50, n_bootstrap=30)
  → Most accurate, well-calibrated

Sparse Data (<30% observed):
  → Monte Carlo
  → Bootstrap struggles with sparsity

Dense Data (>70% observed):
  → Bootstrap or Hybrid
  → Can capture local variation

Large Datasets (>10K rows):
  → Monte Carlo
  → Much faster


🎓 HOW IT WORKS
════════════════════════════════════════════════════════════════════════════════

Monte Carlo:
  1. Temporarily mask some observed values
  2. Impute the masked values
  3. Compare imputed vs. actual
  4. Repeat 100+ times → RMSE distribution
  5. Return mean RMSE ± 95% CI

Bootstrap:
  1. Resample observed values with replacement
  2. Impute on resampled data
  3. Repeat 50+ times
  4. For each missing value: compute percentiles
  5. Return point-wise confidence intervals

Hybrid:
  1. Run Monte Carlo → overall RMSE
  2. Run Bootstrap → point-wise variation
  3. Scale Bootstrap by MC RMSE
  4. Return calibrated intervals
