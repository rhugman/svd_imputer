  .transform(X)        → Impute missing values

  .get_params()        → Get parameters

Attributes (after fitting):

  .is_fitted_          → Whether fitted
  .columns_            → Column names
  .index_name_         → Index name


🎓 TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════════════════

Algorithm: Iterative SVD Imputation
  1. Initialize missing values with column means
  2. Repeat until convergence:
     - Compute SVD: X = U Σ V^T
     - Low-rank approximation: X_approx = U[:,:r] Σ[:r] V^T[:r,:]
     - Update only missing entries
  3. Return imputed matrix

Rank Estimation:
  - Compute SVD on initially-imputed data
  - Calculate cumulative variance: Σ(σ²_i) / Σ(σ²)
  - Select minimum rank where cumulative ≥ threshold

Dependencies:
  - numpy >= 1.20.0 (SVD, numerical operations)
  - pandas >= 1.3.0 (DataFrames, datetime handling)
  - scikit-learn >= 1.0.0 (StandardScaler)
